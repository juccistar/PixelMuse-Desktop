# 设计与交互规范

## 产品与视觉

定位为“商品视觉创作工作台”，采用用户选定的PixelMuse A版黑白极简方向。界面使用中性灰阶；商品图保持真实颜色。成功、警告、危险和编辑蒙版的语义色允许保留，不能为统一黑白而破坏编辑含义。

## 样式和组件

- 页面布局使用CSS Modules；全局字体、滚动条、焦点等基元才放global.css。
- AntD主题使用具体种子值与token一致，不另起一套彩色品牌主题。
- 字体只使用本机local和系统回退；不要在没有资源来源记录时引入在线字体或二进制。
- 加载、空、失败、不可用和成功分别显示；不得用空列表或假成功掩盖失败。
- 长任务显示持久状态与可理解的错误，UNKNOWN显示“已中断”，可以直接重试或结束；请求是否收到完整结果由后台记录，不自动重发。

## 导航与设置

- 全局侧栏管理业务页面与“设置”。人物“模特库”不是AI模型配置。
- 侧栏分为工作台（项目、创作草稿）、素材（资产库、模特库）、创作工具（套图工坊、花型工坊）；设置固定底部并以细线分隔，不重复显示底部品牌签名。默认保持208/172px响应式宽度，使用40px行高、4px行间距、20px组间距与完整中文标签；选中项米白底深色文字，悬停深灰底，键盘焦点有明确描边。品牌与设置不参与中间导航的独立滚动，短窗口和缩放时仍可触达。
- 展开时通过品牌下方按钮收起为68px图标栏：顶部仅保留24×26px标识，导航采用40×40px按钮、20px图标、10px圆角与短分组线；选中项为深灰底、白色图标和细标记。设置与展开按钮集中在底部，键盘顺序与视觉顺序一致，悬停或聚焦显示名称；展开后可拖动右边缘，在172–320px内调宽。右边缘也可聚焦，用左右方向键每次调整8px，Home/End到达最小/最大宽度。收起状态与手动宽度分别保存，拖动结束才写入宽度，取消则恢复；这两项偏好独立于业务工作台的配置侧栏。
- 工作空间位置只在“设置 → 工作空间与数据”配置，不在侧栏、顶栏或弹窗再造入口。
- WorkspacePanel是设置内面板；不要恢复WorkspaceDialog包装或额外open状态。
- 从业务页管理模型时保留来源、草稿、查询串和未提交编辑。隐藏业务页应暂停全局粘贴/快捷键和抢占导航。
- 全局默认只填充新创作或未配置字段；重选当前值也算用户显式选择。

## 分镜、成图与执行记录

- 图片规划顶部配置主图、每SKU图片组与详情画面数，分别显示SKU数、图片组数、画面数和候选张数。用途页签筛选主图/SKU图/详情图；卡片显示编号、用途、冻结SKU名称、指令、候选数、模式和风险。参考缩略图仅使用该分镜实际引用的本项目图片，缺失或读取失败时显示编号规划占位。卡片区域独立滚动，底部保留跨页签选择数量与确认生成操作；确认仍携带当前分镜版本。
- “管理SKU”使用右侧650px抽屉，避让顶部栏，窄窗内滚动且保存/取消始终可达；与任务详情互斥。编辑、批量组合、图片组预览都先修改草稿，共图须显式确认，保存不触发模型。脏草稿关闭、切换阶段、进入设置或离开项目时须确认；隐藏业务页的portal不能继续交互。设计示例商品不进入空目录。
- 成图页将标题、组数和图片数放在同一行，选择与导出工具栏保持紧凑。画廊按主区域的实际可用宽度分列，随两个侧栏宽度变化，不固定依赖整窗宽度。
- 同一生成批次与分镜的候选默认叠放，悬停或键盘聚焦显示翻图及当前图操作；可展开候选缩略条。当前浏览图片、已选下载图片分别管理，翻图不改变下载选择。查询刷新保留当前图，新图成功后置前，旧图保留；大图序列包括收起的候选与编辑版本。
- 规划和成图页的执行过程仅占40px一行摘要，统计项目全部任务；非零失败和已中断优先展示。右侧400px任务抽屉打开后才按页读取正文，每页最多10条，提供全部、进行中、异常和已完成筛选。隐藏业务页时关闭抽屉；历史任务保持只读。中断任务提供直接重试/结束，项目批量操作覆盖符合条件的全部任务，不限当前页；点击即执行，不弹核实表单、风险勾选或费用确认。提交期间禁用重复点击，部分未处理项显示原因。

## 图片和编辑语义

视觉模型识别、人工矩形选区和模型分割必须分别命名。编辑区域和保护区域的蒙版颜色、透明度与像素语义不可因换主题而改变。采集参考图不是商品真值，不自动写入已核实事实。

## 可达性与验证

保留focus-visible、明确label、状态文字与sr-only播报，不仅靠颜色。动效优先transform/opacity，连续交互可用useMotionValue。系统启用减少动态效果时，应用同步关闭AntD组件动画；不能只缩短全局CSS动画，否则弹层可能停留在屏外的定位准备位置。

实际检查默认窗口和最小窗口、滚动后保存、100%至130%缩放、弹窗叠层、画布及返回状态。Electron缩放时Playwright截图可能裁切，应结合原生capturePage、控件坐标和实际点击判断，不能只检查document.scrollWidth。
