## 已知限制与未实测范围

### 数据和升级

- 当前源码将旧桌面库显式事务升级到v12；v11→v12增加规划来源、批次关联及共享修订结果，保留已有分镜、产物、AI设置和回执。已有隔离合成库迁移证据，**真实用户数据库升级未实测**。
- v12升级后不要用公开0.4.8或更旧安装包打开同一数据库；不支持把升级后的数据库交给旧版本降级使用。
- 升级前退出应用，备份完整 userData 和已配置的媒体工作空间；仅复制 SQLite 或素材目录不能恢复完整状态。系统保护密钥可能受 Windows 账户和设备约束。
- 安装器执行、已安装路径启动、覆盖升级和卸载均未实测；Windows 代码签名尚未配置。静态检查与解包 EXE 运行不替代这些验证。

### AI、图片和任务

- 当前专项使用本机假 Provider，不能证明真实服务可用性、模型生成质量、实际计费或第三方失败行为。
- `PIXEL_PROTECTED` 为远端整图生成提供真值输入和保真提示，不能保证返回图逐像素不变。硬蒙版局部合成、保护蒙版和扩图的本地像素边界分别以[应用说明](../README.md)为准。
- AI 帮写页面重新挂载后不会自动采用旧结果；当前页面已跟踪任务的结果读取失败时可重新读取，不据此承诺重挂后自动找回并写入旧结果。
- 完整可靠回执优先按安全规则本地重放；编辑、流水线等可能创建后续付费任务的流程，重启时不能隐式推进，需要用户明确继续。不能承诺所有跨 SDK 版本请求都能重放，实际请求指纹不匹配仍会被拒绝。
- 已发送但无完整回执的请求保守记录为 UNKNOWN，不自动重发。直接重试会保留既有成功产物和历史，新增请求按独立代次计量；结束不发送请求。
- 采集图片与来源信息不是已核验商品事实。人工选区、视觉识别、模型分割和生成式背景各有不同语义。
- 2026-11-10曾修复模型返回候选数／模式不一致，历史专项5文件89项通过。2026-11-12按用户确认的新语义进一步将候选数移出全部规划模型输入／输出，改为本地绑定与独立生图调用；mode仍严格校验并最多纠正一次。这些后续改动已随0.5.0发布，旧0.4.8安装包不包含，详细范围见[验证记录](../VALIDATION.md)。
- 2026-11-09完成[AI调用、上下文与编排审查及优化方案](ai-call-context-optimization-20261109.md)。6项合成探针复现当时的引用失配、普通手动规划顺序、扩图MIME和适配器图片验证边界；探针通过表示复现该次基线行为，不表示真实模型质量已验证。该次审查仅新增资料和本机探针；后续实现与发布以当前进度和验证记录为准。

## 后续维护建议

以下为按风险和交付影响排序的建议，尚非用户批准的工作承诺；执行时按改动范围制定验收并记录结果。

1. **安装与数据连续性**：在隔离 Windows 环境验证全新安装、已安装路径启动、从具代表性的旧安装版覆盖升级、更新重启及卸载；核对完整 userData、媒体、任务和设置保留。使用经授权的数据副本验证真实用户数据库迁移，提前准备备份和回退方案，避免用旧程序打开已升级数据库。
2. **真实服务和失败路径**：在已授权的真实服务测试范围内，以代表性模型检查规划、生图、编辑及分割质量；覆盖超时、断线、取消、未知结果和用户主动恢复，区分模型质量、平台可用性与本地状态正确性。
3. **下次发布的范围验证**：按实际变更选择单元、集成和真实 Electron 窗口场景；涉及持久队列、迁移、IPC 或发布时验证真实行为，并将最终 Source、EXE 和安装器绑定到同一编译及报告。不要将历史完整套件写成新版本结果。
4. **分发与签名**：继续公开分发时，评估并配置 Windows 代码签名，核验发布者与签名；验证更新下载、校验失败、繁忙拒绝、关闭失败、安装及重启，保持 Release 附件与元数据一致。
5. **文档和证据维护**：版本、schema 或能力变更时同步本页、需求和技术栈文档及 `VALIDATION.md`；为每次检查使用独立报告，保留失败及修正记录。旧源码和运行数据继续只作参考，不恢复为新版依赖。
