# 项目模块页面设计稿

日期：2026-11-07。状态：用户选定的四张实施基准，当前源码已按此整理。原图仍是设计示意；实际检查以 [VALIDATION](../VALIDATION.md) 及真实窗口截图为准。

与[复用优先的项目重构方案](project-workflow-refactor-plan.md)配套。四张图由 AI 根据文字说明生成，使用合成示例商品，不是当前应用截图、真实用户素材或真实模型质量验收。成图页导航已在本地与规划页统一。

共用示例：轻行保温杯，奶油白、雾青、陶土三个 SKU；4 个主图目标、3 个 SKU 图目标、5 个详情图目标，共 12 个画面，每画面 2 个候选，预计 24 张。结果图只展示部分可滚动内容。

## 1. 商品准备

![商品准备](../.cache/ui-references/20261107/project-refactor-v2/01-product-preparation.png)

- 左侧保留现有全局导航展开态；商品图与参考图区分展示，支持上传、资产库和参考采集。
- 右侧配置集中在一个面板，常用信息先显示，事实约束、模型、候选数、分辨率、联网研究等通过展开访问。
- AI 自动、指定模板、指定套图仍可选择；保留历史配置入口，不移除现有上下文或高级能力。
- 底部显示实际画面与候选总数，主要操作为“AI 一键规划”。

实施约束：SKU 数量由目录、参与状态与共图规则计算。图中 SKU 数字代表结果摘要，不应实现成可脱离目录随意改变的独立数量输入。商品描述、品牌要求、AI 帮写等未在此静态展开态全部显示的能力，仍按复用清单保留。

## 2. 图片规划

![图片规划](../.cache/ui-references/20261107/project-refactor-v2/02-image-planning.png)

- 主区域为按用途筛选的方案卡片，右侧展示当前画面的编辑面板。
- 方案包含用途、画面要求、文案、引用素材、模板和当前画面参数。
- 技术提示词与高级参数默认收起；可以重做当前方案或明确取消图片需求。
- 执行记录压缩为一行摘要，详细记录通过右侧抽屉访问。
- 底部明确选中数量，主按钮为“确认并生成”。

图中的线稿是解释构图的视觉示意，不能据此承诺现有规划器会额外生成草图。首期实施使用已有素材缩略图与文字方案，不为线稿增加一次生图调用。例示文案也不代表实际商品已核验事实，真实内容仍按现有约束校验。

## 3. 成图与修改

![成图与修改](../.cache/ui-references/20261107/project-refactor-v2/03-results-reviewed.png)

- 画面占据主体，候选继续堆叠显示，当前候选可切换、修改、再生成和下载。
- 按目标保留失败与尚未生成的卡片，用户直接看到未完成内容。
- “采用版本”与“下载勾选”分开；已经采用的当前版本，实施时显示“已采用”或禁用重复采用动作。
- 顶部提供已采用下载、更多导出和导出记录，底部提供详情排序与长图导出。
- 全局侧栏收起供参考，实际使用尊重用户保存的展开/收起偏好，不因切阶段强制折叠。

采用 8、待选择 2、失败 1、未生成 1 是示例的目标统计，合计 12。图中只展示部分目标，具体编号与用途以实际需求记录为准。

## 4. 单图编辑工作区

![单图编辑](../.cache/ui-references/20261107/project-refactor-v2/04-single-image-editor.png)

- 从成图卡片的“修改这张”进入，保持第三阶段，不增加第四个强制流程步骤。
- 大图画布为主体；旁边保留选区、画笔、保护和扩图工具，下方保留历史版本。
- 右侧填写本轮修改要求，参考用途、模型参数、原图约束与编辑记忆可展开查看。
- 本图展示“先审阅方案”的待确认状态，用户确认后生成独立新版本，原图保留。
- 其他编辑执行方式继续遵守原有确认和自动续接规则；更改输入使旧预览失效。

蒙版颜色和轮廓仅为设计示意，实施必须沿用现有可编辑区/保护区的实际语义。这不代表人工选区已具备自动模型分割能力。

## 落地边界

本组图主要确定页面信息层次、主操作与图片区域比例。精确字号、侧栏宽度、图标、响应式布局及控件状态以现有[设计规范](design-system.md)和真实 Electron 验证为准，不把 AI 生成的像素尺寸直接当组件规格。

只修改项目工作区的组织和衔接；模型协议、上下文构建、模板与套图知识、持久队列、请求账本、生成与编辑链按重构方案复用。

当前落实边界：模板与套图在商品准备中选择，再对目标进行规划；已发布画面的模板身份只读。规划提供整套重做、受影响目标更新及取消需求，没有新增任意单画面重规划接口。采用、详情顺序和导出历史已持久化；历史导出若没有记录输出列表，不补猜其内容。编辑重开可恢复未结束轮次，确认执行后台保存的方案和蒙版；历史笔刷蒙版未重新载入画布像素，重新规划使用当前画布选区。
